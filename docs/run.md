# Run Spotcraft

For whoever owns the server: setting Spotcraft up, adding apps, and looking after them from the
dashboard. You need a server you can SSH into, a domain, and Docker images of your apps.

1. [Getting started](getting-started.md): create the server, point the domains, deploy
   Spotcraft and add your first app. It ends with upgrading and rolling back.
2. [Using the dashboard](dashboard.md): every page, for all apps and for one, and what you can
   do from each.
3. [Backups and restoring](guides/backups.md): nightly backups to a bucket, and getting an app
   or the whole server back.
4. [Moving an app into the user pool](guides/move-into-the-pool.md): for an app made before the
   pool, once its developers have a version ready.

Writing the apps themselves? [Build apps](build.md) is for their developers.
